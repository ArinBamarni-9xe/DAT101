1. What is the difference between invoking and creating a function?

    Creating (defining) a function gives it a name and describes the code it will run. Invoking (calling) it runs that code.

  2. Explain the syntax regarding semicolons and code blocks.

    Semicolons end statements, such as assignments, function calls, and return statements. Curly braces group statements into a code block, such as a function body. A block itself does not need a semicolon after its closing brace when it belongs to a function, loop, or conditional.

  3. What happens when we try to store values from a function when it doesn't return any?

    The function call evaluates to undefined, so the variable receives undefined.

  4. How do we separate parameters from each other when creating a function?

    Separate parameters with commas inside the parentheses, for example function add(first, second) { ... }.

  5. Explain how parameter names are related during the invocation and creation of a function.

    Arguments in a function call are assigned to parameters by position, not by name. The parameter names are local names used inside the function and do not need to match the names of the variables passed as arguments.

  6. Explain why a parameter is undefined when a function call is missing a parameter.

    JavaScript assigns undefined to any parameter that has no corresponding argument, unless a default value is specified.

  7. Explain what happens when we use recursive functions.

    A recursive function calls itself, creating another function call each time. It needs a base case to stop; without one, calls continue until the program runs out of call stack space.
